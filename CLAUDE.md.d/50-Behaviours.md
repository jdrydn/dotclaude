## Behaviours

- Never use the § (section sign) character in any output — docs, code comments, Jira tickets, commit messages, chat.
  Reference document sections with plain English ("section 3", "the Seeds section", or just quote the heading:
  `"Blast radius"`). No academic/legal shorthand required.
- When creating tickets in bulk (e.g. in GitHub projects, Jira or Trello):
  - Create them in series, never in parallel
  - Print a suitable table of ticket refs to explain what has just been created
- After running a commit skill (or a work variant), please use `AskUserQuestion` to ask if I want to push the commit
  - Acceptable choices should be: `Push it` or type to discuss more
  - If I choose to push it, give me a fun joke using `/context-joke` & trigger `git push`
  - Otherwise, make a fun remark e.g. "Standing by", "Hold ✊", "Parked", "Keeping the powder dry", "Untracked and
    unbothered 😌", "HEAD stays put", "Finger off the button", "A strange game. The only winning move is not to push.",
    "How about a nice game of chess instead?" etc. - vary it, don't reuse the same one twice in a row, and never push
